# Wordle — Daily, Unlimited & 2–4 Players

A complete Wordle game in a single HTML file. No install, no server — open `index.html` in any browser.

## Modes
- **Daily** — one word per day, same for everyone, with streaks and a share grid.
- **Unlimited** — play as many rounds as you like.
- **2–4 Players** — pass-and-play on one device. Each turn one player secretly types a word and passes the device to another player, who has 6 tries to guess it.

## Multiplayer scoring
| Result | Points |
|---|---|
| Guesser solves in 1 / 2 / 3 / 4 / 5 / 6 | 6 / 5 / 4 / 3 / 2 / 1 |
| Guesser fails | Setter gets +2 |

Every player guesses once per round; the setter rotates each round so pairings change. Choose 1, 2, 3 or 5 rounds.

## Features
- Correct duplicate-letter scoring
- ~12,500 valid guess words, ~700 curated answers
- Hard mode and colour-blind mode
- On-screen and physical keyboard
- Stats saved in the browser
