# Times Table Galaxy

A fun, iPad-friendly times tables game for kids.

**Play:** https://lenkasacademy-pixel.github.io/times-table-galaxy/

- 🎈 **Balloon Pop** – pop the balloon with the right answer
- 🚀 **Rocket Race** – 60 seconds, fly your rocket to Saturn
- 🔭 **Table Explorer** – see how each table works and discover every answer

## Game Night

Six party games for 3–4 players on one iPad: Dimaag Milao, So Clover!, Smart10, Cross Clues, Things in Rings and Love Letter.
